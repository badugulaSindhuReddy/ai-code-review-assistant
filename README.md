# AI-Powered Code Review Assistant

A full-stack AI developer tool that helps users review code, identify bugs, suggest improvements, and explain optimized solutions. The application uses a React and TypeScript frontend, a Python backend, and an AI API integration to generate intelligent code feedback.

## Features
- Code snippet input with language selection
- AI-generated bug detection and improvement suggestions
- Optimized code recommendations
- Explanation of logic and complexity
- REST API-based frontend/backend communication

## Tech Stack
React.js, TypeScript, Python, Node.js, REST APIs, OpenAI API, AWS

## Why I Built This
I built this project to explore AI-powered developer tools and improve coding productivity by automating repetitive code review tasks.
